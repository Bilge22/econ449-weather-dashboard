# Weather-driven Demand Sensing — academic dashboard (ECON 449)

Live page: `index.html` (GitHub Pages).

**Academic demonstration for an ECON 449 course project — not an official Arçelik website.**

- **Sales figures are synthetic.** They were simulated for the exercise and are not actual Arçelik or Beko sales.
- **Weather data are real:** daily maximum temperature from the Open-Meteo Historical Weather and Forecast APIs (CC BY 4.0), 2022–2026, with a 1991–2020 ERA5 reference.
- **Hypothetical scenarios** on the Seasonal Timing page are illustrations from the simulation, not forecasts or causal estimates.
- Descriptive analytics only; no forecasting models, machine learning or optimisation.

The page is a single self-contained HTML file (data, styles and the ECharts 5.6.0 library are embedded); it makes no network requests.
